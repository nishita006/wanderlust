# Wanderlust - Airbnb Clone

Live Link: Coming Soon | GitHub: https://github.com/nishita006/wanderlust

A full-stack vacation rental platform inspired by Airbnb.

## Features
- User Authentication (Signup/Login) with Passport.js
- Create, Edit, Delete Listings
- Reviews & Ratings
- Map Integration with Mapbox

## Tech Stack
Node.js, Express.js, MongoDB, EJS, Bootstrap, Cloudinary

## How to run locally?
1. git clone https://github.com/nishita006/wanderlust.git
2. npm install
3. Create .env file with ATLASDB_URL and SECRET
4. node app.js
